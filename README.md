# Zocadama 8051 Studio

**Learn. Simulate. Build.**

A website for learning the 8051 microcontroller. It will grow into lessons, a CPU simulator and a circuit builder.

## Current status

| Part | Status |
| --- | --- |
| Website skeleton and styling | Built, needs your testing |
| 8051 pin explorer (reference diagram) | Built, needs your testing |
| Lessons | Not started |
| CPU simulator | Not started |
| Circuit designer | Not started |

The simulator is **not** built yet. Nothing here pretends otherwise.

## Files

- `index.html` – the page
- `styles.css` – colours and layout
- `main.js` – mobile menu and the pin explorer
- `ROADMAP.md` – the plan

## How to run it

Double-click `index.html`. It opens in your browser. No install needed.

## Rules for this project

- Never commit passwords, API keys or tokens.
- A feature is only marked Done after it has been tested.
