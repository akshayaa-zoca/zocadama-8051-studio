How to use it

1. Pick a program

Choose an example, or type your own bytes such as 74 25 24 17 80 FE. Each byte is two hexadecimal digits.

2. Step or Run

Step runs one instruction. Run keeps going until a breakpoint, a fault, or a jump-to-itself (the usual “finished”). Pause and Reset do what they say.

3. Read the panels

Highlighted values changed on the last step. The “Last instruction” panel lists every change, and a red message explains any fault.

What it can and cannot do

This is not a full 8051 or AT89S52 simulator. It models a small, tested subset.

Works today

  • Hexadecimal machine-code input and five examples
  • Step, Run, Pause, Reset, run speed and breakpoints
  • A, B, PC, SP, PSW with the CY, AC, OV and parity flags
  • Register banks R0–R7 and 256 bytes of internal RAM, including upper RAM reached indirectly
  • Moves, add/subtract with carry, logic, jumps, DJNZ, LCALL/RET and the stack
  • Clear messages for unsupported instructions and other faults

Not available yet

  • Assembly-language input (an assembler is planned)
  • Timers, interrupts and the serial port
  • DPTR instructions, MOVC and MOVX, external memory
  • MUL, DIV, rotates and most bit instructions
  • Real timing: it counts instructions, not machine cycles
  • Port pins and circuits (ports are stored values only)

Technical details and every simulator choice are in docs/SIMULATOR.md.
